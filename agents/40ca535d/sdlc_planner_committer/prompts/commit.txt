/commit sdlc_planner feature {"number":1,"title":"Add optional MCP server support with FastMCP","body":"# Add Optional MCP Server Support with FastMCP\n\n## Overview\n\nImplement MC Logger as a Model Context Protocol (MCP) server using FastMCP, allowing AI assistants to query and analyze logs through standardized MCP tools, resources, and prompts. The MCP server should be an **optional feature** using Python's extras mechanism to avoid adding dependencies for users who don't need it.\n\n## Motivation\n\n- **AI-First Design**: MC Logger is already optimized for AI-assisted debugging, but currently requires manual function calls\n- **Standardization**: MCP is the emerging standard for AI tool integration (Claude Desktop, Cursor, ChatGPT, etc.)\n- **Zero Overhead**: Users who only need logging shouldn't be forced to install FastMCP\n- **Professional Pattern**: Follow industry best practices (same pattern as `pydantic-ai[anthropic]`, `httpx[http2]`)\n\n## Proposed Solution\n\n### Installation Pattern\n\n```bash\n# Core logging only (current behavior)\nuv add mc-logger\n\n# With MCP server support (new)\nuv add \"mc-logger[mcp]\"\n\n# Development with MCP (new)\nuv add \"mc-logger[dev,mcp]\"\n```\n\n### Architecture\n\nCreate a new **optional module** `mc_logger/mcp/` that wraps existing `mcp_tools.py` functions as FastMCP tools:\n\n```\nmc_logger/\n├── __init__.py           # Core exports (no MCP dependency)\n├── models.py\n├── storage.py\n├── context.py\n├── core.py\n├── middleware.py\n├── mcp_tools.py          # Existing query functions (no MCP dependency)\n└── mcp/                  # NEW: Optional MCP server module\n    ├── __init__.py       # MCP server exports with import guard\n    ├── server.py         # FastMCP server implementation\n    ├── resources.py      # MCP resources (log streams)\n    ├── prompts.py        # MCP prompts (debugging workflows)\n    └── cli.py            # CLI entry point (optional)\n```\n\n### Key Design Decisions\n\n1. **Separate Module**: Keep MCP code isolated in `mc_logger/mcp/` to maintain separation of concerns\n2. **Import Guards**: Use try/except to provide helpful error messages if fastmcp not installed\n3. **Tool Wrappers**: Wrap existing `mcp_tools.py` functions (don't duplicate logic)\n4. **MCP Resources**: Expose log streams as MCP resources for real-time access\n5. **MCP Prompts**: Provide debugging workflow templates\n6. **Environment Variables**: Support configuration via env vars (Docker/Claude Desktop friendly)\n7. **Optional CLI**: Provide `mc-logger-mcp` command for easy server startup\n8. **Zero Breaking Changes**: Existing users unaffected, no new required dependencies\n\n## Implementation Tasks\n\n### Phase query_logs\n**Purpose**: Query logs with various filters  \n**Parameters**:\n- `time_range` (optional): \"5m\", \"2h\", \"1d\"\n- `request_id` (optional): Filter by request ID\n- `session_id` \n**Parameters**:\n- `start_time` (required): Start time (\"10m\" or ISO timestamp)\n- `end_time` (optional): End time (defaults to now)\n- `label` (default: \"debug_session\"): Descriptive
